# Project Proposal

This directory contains the formal proposal and related project documentation for HackViz.

## Project

**HackViz — Explainable, Transfer-Learning-Enabled Intrusion Detection for Behavioral Anomalies**

The system aims to detect anomalous user/system behavior from event sequences using unsupervised autoencoders while improving explainability and reducing the cold-start burden through transfer learning.

Detailed proposal material will be added as the project documentation is finalized.
