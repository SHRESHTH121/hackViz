# ML Service

Python-based machine-learning service for HackViz.

Planned components:

- `preprocessing/` — CERT log cleaning, normalization, feature extraction, and session construction
- `models/` — LSTM/GRU, Transformer, and hybrid autoencoders
- `training/` — training and transfer-learning workflows
- `inference/` — anomaly scoring and model serving
- `explainability/` — attention extraction and event-level explanations
