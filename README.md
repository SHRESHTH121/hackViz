# hackViz — Explainable Insider-Threat Detection

hackViz is an explainable insider-threat detection platform that combines a **decoder-only Transformer-based anomaly detection model** with **Qwen2.5-3B-Instruct for explainability**. These are two separate components with distinct responsibilities:

- **Anomaly detection — Decoder-only Transformer:** analyses employee activity patterns and identifies potentially anomalous behaviour.
- **Explainability — Qwen2.5-3B-Instruct (via local Ollama):** interprets the detection result alongside relevant employee and activity context, then produces a human-readable explanation and recommended next step.

The system also uses role, department, historical behaviour and supporting behavioural indicators to provide context for assessment. Qwen is used to explain the result; it is **not** the anomaly-detection model.

A Chrome extension streams live browser activity (navigation and download metadata only) to a FastAPI backend, which stores it in PostgreSQL alongside fictional CERT-style historical data. The React dashboard presents activity, detection results and their explanations. Each assessment can include:

- a risk level and confidence estimate
- a plain-language explanation generated by Qwen
- a recommended next step
- the event IDs that support the assessment

Analysts can open each cited event in the dashboard.

```
Chrome extension ──► FastAPI ──► PostgreSQL ──► Decoder-only Transformer
                                                   │
                                                   ▼
                                          Anomaly detection result
                                                   │
                         Employee role + history ─┤
                                                   ▼
                                      Qwen2.5-3B-Instruct
                                      (explanation via Ollama)
                                                   │
                                                   ▼
                                    Explainable alert ──► React dashboard
```

Everything runs locally; no activity data is sent to a hosted LLM service. Alerts are investigative leads for human review, not proof of misconduct. All employees and historical records are fictional.

---

## AI components

| Component | Technology | Responsibility |
|---|---|---|
| Anomaly detection | Decoder-only Transformer-based model | Detects potentially anomalous patterns in employee activity |
| Explainability | Qwen2.5-3B-Instruct, served locally through Ollama | Converts detection outputs and relevant context into human-readable explanations and recommended actions |

The two models serve different stages of the pipeline. The Transformer performs anomaly detection; Qwen provides the explanatory layer. This separation keeps the detection decision distinct from its natural-language interpretation.

## Requirements

| Component | Version | Notes |
|---|---|---|
| OS | Windows 10 / 11 | developed and tested on Windows 11 |
| RAM | 16 GB recommended | runs on CPU; no GPU needed |
| Python | 3.12 | backend |
| Node.js | 20 or newer | dashboard |
| PostgreSQL | 16 | official installer |
| Ollama | 0.40+ | with model `qwen2.5:3b` (~1.9 GB download) |
| Google Chrome | current | for the activity extension |

Python packages are listed in `backend/requirements.txt` and JavaScript packages in
`frontend/package.json`; both are installed during setup.

## Setup (PowerShell)

### 1. Get the code
```powershell
git clone https://github.com/SHRESHTH121/hackViz.git
cd hackViz
```

### 2. PostgreSQL — create the database
Install PostgreSQL 16 (`winget install PostgreSQL.PostgreSQL.16`) and note the `postgres` password, then:
```powershell
$env:Path = "C:\Program Files\PostgreSQL\16\bin;$env:Path"
psql -U postgres -h localhost -c "CREATE DATABASE hackviz;"
```
The backend creates all tables and loads the dataset automatically on first start.

### 3. Ollama — download the model
```powershell
ollama pull qwen2.5:3b
ollama list          # should list qwen2.5:3b
```

### 4. Backend (FastAPI) — first terminal
```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1      # if blocked: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env                      # set DATABASE_URL=postgresql+psycopg://postgres:<password>@localhost:5432/hackviz
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
Check it is running: <http://127.0.0.1:8000/api/health>

### 5. Dashboard (React) — second terminal
```powershell
cd frontend
npm install
npm run dev
```
Open **<http://localhost:5173>**. You should see 10 fictional employees with their historical activity.

### 6. Chrome extension
1. Open `chrome://extensions` and switch on **Developer mode**.
2. Click **Load unpacked** and select the `extension` folder.
3. Open the hackViz extension, confirm the monitoring notice, enter an employee ID (e.g. `EMP002`)
   and click **Pair**.

Browse normally. Events appear in the dashboard within seconds, and the LLM assesses them
automatically after 5 new events, or 90 seconds of inactivity. You can also click **Analyze Now**
on any employee profile. On a CPU each assessment takes about 30–110 seconds.

### Shortcut: helper scripts
After the one-time setup above, the services can be started from the project root, each in its own
PowerShell window:
```powershell
.\scripts\start-ollama.ps1
.\scripts\start-backend.ps1
.\scripts\start-frontend.ps1
```

### Run the tests (optional)
```powershell
.\scripts\run-tests.ps1               # includes real LLM inference, ~9 min
.\scripts\run-tests.ps1 -SkipOllama   # quick run, ~30 s
```
